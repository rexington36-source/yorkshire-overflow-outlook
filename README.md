# Yorkshire Overflow Outlook

Static page showing the modelled chance that each Yorkshire Water storm overflow starts discharging in
the next 6, 12 and 24 hours. `latest.json` is replaced hourly.

Modelled estimates, not measurements. Storm overflows discharging in heavy rain are permitted under
environmental permits and are not in themselves unlawful. The underlying Event Duration Monitoring data
has not been verified by the Environment Agency.
